# Amazon E-Commerce Sales Performance Analysis (SQL)

## Project Overview
This project analyzes transaction-level retail sales data from Amazon India seller central records to uncover revenue drivers, regional demand hubs, top-performing product categories, and buyer concentration metrics.

## Tech Stack
* **Database engine:** SQLite / SQLiteOnline[cite: 1, 6]
* **SQL Techniques:** Window Functions (`DENSE_RANK() OVER`), Common Table Expressions (CTEs), Conditional Filtering, String Manipulation (`SUBSTR`), Aggregations (`SUM`, `COUNT DISTINCT`)[cite: 8, 9, 10]

## Key Findings & Business Insights
* **Top Revenue Drivers:** **Set** and **Kurta** categories dominate sales, contributing **49.85%** and **27.10%** of total business revenue, respectively.
* **Geographical Hotspots:** **Maharashtra** (18,002 orders, ₹1.22Cr revenue) and **Karnataka** (14,085 orders, ₹96.5L revenue) represent the highest customer demand regions.
* **High-Value Hubs:** Top postal codes generating maximum lifetime order value are concentrated in **Noida (201301)** and **Gurugram (122001)**[cite: 9].
